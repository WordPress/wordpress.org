# Security Policy

This repository holds the code behind WordPress.org and its sister sites: the Plugin and Theme Directories, the Support Forums, translate.wordpress.org, the WordPress.org APIs, and more.

The WordPress Security Team believes in Responsible Disclosure. Please alert the security team immediately and privately of any potential vulnerability, and do not open a public issue, pull request, or Trac ticket for it.

## Reporting a Vulnerability

Security issues must be submitted via [HackerOne](https://hackerone.com/wordpress). Please read the full policy there before submitting a report: it lists the projects and infrastructure the program covers, and what is in scope for each.

The security team can also be reached at security@wordpress.org.
